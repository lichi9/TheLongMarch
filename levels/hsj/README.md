# levels/hsj

**负责人：hsj**
关卡事件：总路程回忆拼图（锁倒数第二）
剧情顺序：不以文件夹名为准，只由 `core/route.js` 决定

---

## 这个格子归你

| 文件 / 目录 | 作用 | 是否入库 |
| --- | --- | --- |
| `index.html` | 入口页，主程序加载的就是它 | 入库 |
| `level.js` | 关卡逻辑。**通关必须 postMessage**，见下文 | 入库 |
| `meta.js` | 关卡名，显示在选关卡片上，改成你的 | 入库 |
| `style.css` | 关卡样式，舞台固定 1280×720，`html` / `body` 随便写 | 入库 |
| `cover.webp` | 选关面板里的封面，换成你自己的 | 入库 |
| `assets/` | 别人 clone 下来必须有的素材 | 入库 |
| `test/` | 参考样例，能跑但**别改它** | 入库 |
| `_draft/` | 截图、试做贴图、参考图 | **不入库，随便扔** |

三个文件**已经建好了**，直接改就行，不用自己新建。
文件名和路径都不能变——主程序固定加载 `levels/<缩写>/index.html`。

## 先跑一遍

双击根目录的 `index.html`，点一下屏幕就该通关（背景变红）。

这一步只是确认三件事：浏览器能打开、不用装任何东西、你本地环境正常。
跑通了再往里填自己的东西。

`test/` 里是一份一模一样的参考样例，**改坏了可以对着它比**，别去改它本身。

## 关卡名：改 `meta.js`

卡片上显示的名字来自 `meta.js`：

```js
window.CZ_META['你的缩写'] = { name: '四渡赤水·一渡' };
```

改完刷新页面就生效。多人共一个地点时，建议加个区分（「·一渡」「·二渡」），
否则几张卡片看起来一模一样。

## 通关一定要 postMessage

这是最容易漏的一步：关卡跑完，但地图那边不知道，界面就一直挂着。

```js
window.parent.postMessage({ type: 'cz:done' }, '*');
```

`finish()` 里已经写好了，照抄就行。**完整接口说明见 [`docs/level-api.md`](../../docs/level-api.md)。**

## 边界

- 只改 `levels/hsj/` 里的东西
- `index.html`、`core/`、根 `assets/`、`docs/`、`.gitignore` 只读
- 别人的关卡能看能抄，不能提交任何改动
- 不改文件夹名，不改 `level.js` 里的 `id`

## 封面图（选关面板用）

`cover.webp` 是选关面板里代表你的那张卡。现在是占位图，**换成你自己的**：

- 路径固定 `levels/<缩写>/cover.webp`，文件名和位置都别改
- 建议 **480×320（3:2）**，横图
- 单张 ≤ 300KB，超了就转 WebP 压一下
- 内容随意：场景截图、概念图、手绘、海报都行
- **换完刷新页面就能看到，不用改任何代码**

占位图上写着「封面待填」，就是提醒你还没换。

## 素材

判断标准一句话：**别人 clone 下来，你这关还能不能玩。**

- 需要 → 放 `assets/`，并且必须提交
- 不需要（草稿、截图、参考图）→ 放 `_draft/`，它已经被 `.gitignore` 忽略
- 单文件 ≤ 2MB，单关 `assets/` ≤ 8MB，全小写 ASCII + 连字符
- 禁视频、GIF、PSD
