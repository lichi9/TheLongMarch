## 这个格子归你

| 文件 / 目录 | 作用 | 是否入库 |
| --- | --- | --- |
| `level.js` | 关卡逻辑，导出 `mount(root, ctx)` | 入库 |

`level.js` 和 `style.css` 目前是空的，开工时**自己在 `levels/mhm/` 里新建**。
文件名大小写不要变：全小写。

## 先跑一遍 test/

`test/` 里放了一份能直接跑的**最小关卡**：双击 `test/index.html`，点一下屏幕就通关。

它的作用是让你先确认三件事：

1. 浏览器能打开、不用装任何东西
2. 关卡长什么样：一个 `mount(root, ctx)`，往 `root` 里塞 DOM，通关时调 `ctx.complete()`
3. 你本地的编辑器 / 浏览器一切正常

**看懂之后，把 `level.js` 和 `style.css` 复制到 `levels/<缩写>/` 下改成你自己的**，
`test/` 留着当参照，别删。

## 边界

- 只改 `levels/mhm/` 里的东西
- `index.html`、`core/`、根 `assets/`、`docs/`、`.gitignore` 只读
- 别人的关卡能看能抄，不能提交任何改动
- 不改文件夹名，不改 `level.js` 里的 `id`

## 封面图（选关面板用）

`cover.webp` 是选关面板里代表你的那张卡。现在是占位图，**换成你自己的**：

- 路径固定 `levels/<缩写>/cover.webp`，文件名和位置都别改
- 建议 **480×320（3:2）**，横图
- 单张 ≤ 300KB，超了就转 WebP 压一下
- 内容随意：场景截图、概念图、手绘、海报都行
- **换完刷新页面就能看到，不用改任何代码**

占位图上写着「封面待填」，就是提醒你还没换。

## 素材

判断标准一句话：**别人 clone 下来，你这关还能不能玩。**

- 需要 → 放 `assets/`，并且必须提交
- 不需要（草稿、截图、参考图）→ 放 `_draft/`，它已经被 `.gitignore` 忽略
- 单文件 ≤ 2MB，单关 `assets/` ≤ 8MB，全小写 ASCII + 连字符
- 禁视频、GIF、PSD
