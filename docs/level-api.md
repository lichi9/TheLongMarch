# 关卡接入说明

写给做关卡的人。看完这份，你不需要碰主程序一行代码。

---

## 一、你的文件夹里有什么

以 `levels/hzh/` 为例：

```
levels/hzh/
├─ index.html     入口页，主程序加载的就是它（一般不用改）
├─ level.js       关卡逻辑，你主要改这个
├─ style.css      关卡样式，你改这个
├─ cover.webp     选关面板里的封面，换成你自己的图
├─ assets/        关卡要用到的图片、音频，放这里
├─ _draft/        草稿、截图、参考图，随便扔，不会入库
├─ test/          一个能跑的参考样例，**别动它**
└─ README.md      你的分工说明
```

`test/` 里是一份一模一样的示例，留着对照用。**要改的是根目录那三个文件。**

---

## 二、舞台是固定 1280 × 720

主程序把整个关卡层当成一块 **1280×720 的画布**，再整体缩放去适配每个人的窗口。
所以你**按 1280×720 摆位置就行**：

- 想铺满 → `width: 100%; height: 100%`
- 想精确摆放 → 直接用像素，比如 `left: 320px; top: 180px`
- **不要**自己写响应式、不要读 `window.innerWidth`

同一份代码在 1366 的笔记本和 2560 的显示器上，看到的构图完全一样。

## 三、接入只需要做对四件事

### 1. 入口必须是 `index.html`

主程序固定加载：

```
levels/<你的缩写>/index.html
```

文件名、路径都不能变，也不能挪到子目录里。

### 2. 通关必须 `postMessage`

这是最容易漏的一步。你的关卡跑起来了、打通了，但如果没通知主程序，
地图那边会一直挂着，界面不会返回。

```js
window.parent.postMessage({ type: 'cz:done' }, '*');
```

消息体里的 `type` 必须是 `'cz:done'`，别的一个字都不能差。

**完整写法**（`level.js` 里已经有，直接照抄）：

```js
function finish() {
  // 嵌在主程序里
  if (window.parent && window.parent !== window) {
    window.parent.postMessage({ type: 'cz:done' }, '*');
    return;
  }
  // 单独双击打开时，自己收尾
  // ...
}
```

判断 `window.parent !== window` 是为了让同一个文件既能被主程序加载、
也能双击单独调试。

**想在关卡里放个「返回」按钮**，发另一条消息，不用等主程序右上角那个：

```js
window.parent.postMessage({ type: 'cz:exit' }, '*');
```

它和「退出关卡」按钮效果一样：关掉关卡、回到选关面板，**不算通关**。
适合你的画面右上角被 UI 占满、或者想自己控制返回位置的情况。

### 3. 关卡名改 `meta.js`

`levels/<你的缩写>/meta.js` 决定卡片上显示的名字：

```js
window.CZ_META['你的缩写'] = { name: '四渡赤水·一渡' };
```

改完刷新页面就生效，不用碰主程序。没有这个文件（或名字为空）时会退回显示你的缩写。

### 4. 封面图放对位置

`levels/<你的缩写>/cover.webp`，480×320（3:2）横图，≤ 300KB。
换完刷新页面就能看到，不用改代码。

## 四、主程序会怎么对你

| 时机 | 主程序做什么 |
|---|---|
| 点选关卡片 | 把 `index.html` 装进一块 **1280×720 的 iframe**，再整体缩放到窗口 |
| 收到 `cz:done` | 立刻记录通关、关掉 iframe、回到选关面板 |
| 收到 `cz:exit` | 关掉 iframe、回到选关面板，**不算通关** |
| 点右上角「退出关卡」 | 同上，不算通关 |

**加载出问题会直接写在屏幕上。**
如果 6 秒还没加载完，主程序会盖一层红字提示，
告诉你去查 `levels/<你>/index.html` 和浏览器控制台——不用自己对着白屏猜。

**关掉时 iframe 会被清空（`src` 设成 `about:blank`）。**
所以每次进关都是全新一局，不能指望「上次玩到哪」还留着。
要做自己的进度记忆，存 `localStorage`，用你自己的 key。

---

## 五、不要做的事

**1. 不要改 iframe 外面的东西。**
你在 iframe 里，碰不到主程序的 DOM，也不该去碰。`parent.document.xxx` 一律别写。

**2. 只发两种消息，别的别发。**
主程序只认 `cz:done`（通关）和 `cz:exit`（退出）。发别的一律被忽略。

**3. 不要自己写响应式。**
舞台固定 1280×720，主程序负责缩放。你自己再读 `window.innerWidth` 算一遍，
会和主程序的缩放叠加，位置就歪了。

**4. 不要改 `test/` 里的文件。**
它是所有人的参照标准，改了会让自己和文档对不上。

**5. file:// 下读不了自己的 JSON。**
纯本地打开时，`fetch` / `XMLHttpRequest` 会被浏览器拦掉——和 meta.js 为什么要用 script 标签是同一个原因。
关卡需要数据（题库、剧情、地图），直接写进 JS 文件里，或者像 meta.js 一样挂到 window 上。
起本地服务器后 fetch 才可用，但那只是调试时的事，交付的游戏按「没有 fetch」来写。

**6. 不要动核心文件。**
下面这些是所有人共用的，**只能读不能改**：

```
index.html  map.html          开始页和地图
core/                         save.js / map.css / menu.css
assets/brand/                 菜单图、地图底图
docs/                         文档
tools/                        构建与截图脚本
.gitignore  .gitattributes
```

改它们会直接影响别人，而且冲突很难合。确实需要改就找负责人。

## 六、本地怎么测

**方式一：单独跑（快）**

双击 `levels/<你>/index.html`，浏览器直接打开。
这时候没有主程序，通关时走的是「自己收尾」那条分支，画面变红、显示「通关」。

**方式二：接进游戏跑（真实）**

从 `index.html` 开始游戏 → 地图上点到你那一站 → 点卡片 → 确认能进、
点击后能自动回到面板。这条路通了，才算真的接好了。

## 七、样式隔离说明

你的 CSS 跑在独立文档里，**不会影响主程序，主程序的样式也不会影响你**。
所以 `html`、`body`、`*` 这些选择器可以放心用。

> **别写 `:host`。** 那是 Shadow DOM 的根选择器，在当前这套 iframe 方案里
> 匹配不到任何元素，写上去等于整份样式失效、画布退回原始尺寸。
> `levels/hsj` 早期就栽在这上面，改回来才正常。

前提是主程序继续用 iframe 加载。**如果哪天改成直接注入 DOM，这份文档会更新**，
届时需要把根选择器换成 `:host` 或加作用域前缀——现在不用管。

## 八、常见问题

**Q：点了没反应，也不回面板？**
八成是 `postMessage` 没写、或者 `type` 拼错了。打开浏览器控制台看有没有报错。

**Q：卡片是灰的，点不动？**
这一站里前面的关卡没通关。地点内是按成员顺序解锁的，左边的没打完，右边进不去。

**Q：封面还是「封面待填」？**
`cover.webp` 没换，或者文件名/路径不对。

**Q：改完代码没变化？**
浏览器缓存。`Ctrl + F5` 强制刷新。

## 附：做完之后，关怎么放出来

写完不等于玩家就能玩到。`core/save.js` 顶上有一个 `SHIPPED` 数组，
**只有列在里面的关卡才会出现在地图上**。

没列进去的时候：

- 卡片不生成，玩家看不到你这一关
- 你的 id 不计入进度分母
- 你所在的那个站点如果一关都没放出来，会在地图上显示成灰色小虚线，
  点上去提示「这一站还在赶制」，而且**不会把后面的站点卡死**

做好了就把 id 加进去（这行通常是负责人改）：

```js
var SHIPPED = [
  'mt',
  'zsb',
  'ljm', 'qrz',
  ...
];
```

刷新页面就放出来了，解锁链、进度数字、尾声判定都会自动跟着变。
半成品留在仓库里完全没问题，不会影响任何人。
