# 长征：拾光

21 人协作的闯关小游戏 · 纯前端 · 双击 `index.html` 就能玩 · 零构建、零依赖、断网可运行

---

## 这是什么

玩家从于都出发，沿长征路线经过 8 个地点。每个地点下有若干个关卡，
由团队成员各自独立完成，互不干扰。走到会宁会师，播一段黑屏金字的尾声，回到开始页。

游戏没有后端、不联网，全部逻辑跑在浏览器里。

---

## 怎么玩

**双击 `index.html`。** 不需要装任何东西。

1. 点「开始」→ 选一个存档位（8 个挡位，空的点一下就新建）
2. 地图上点红色的印章 → 弹出这个地点的选关面板
3. 点卡片进关卡 → 通关后自动记录，回到面板继续
4. 一个地点里的关卡**全部通关**，才会解锁下一个地点
5. 走完会宁会师，看尾声，回开始页

**存档在浏览器本地**（`localStorage`），8 个挡位，每次完成关卡和返回主页面都会自动存。
换设备、换浏览器、清缓存都会丢——这是纯前端的取舍，没有服务器。

调试参数：`?reset=1` 清空当前挡位进度（会先弹一次确认），`?all=1` 把已放出的关卡全标成通关，直接看尾声。

## 关卡放出：不是全做完才能上线

`core/save.js` 顶上有一个 `SHIPPED` 数组，**只有列在里面的关卡算数**：

- 不在里面的关卡不出现在选关面板，玩家看不到也点不进
- 不计入进度分母，也不参与「这一站全通了没」的判定
- 文件照旧留在 `levels/` 里，做好之后把 id 加进数组，刷新页面就放出来了

解锁链、进度数字、「全部通关播尾声」的判定都会自动跟着这个数组走，
改一处就够了。一关都还没放出的站点（比如现在的会宁会师）在地图上标成
灰色小虚线，点上去提示「这一站还在赶制」，不会把后面的站点卡死。

## 关卡怎么接进来

**入口固定为 `levels/<你的缩写>/index.html`，通关时发一条消息：**

```js
window.parent.postMessage({ type: 'cz:done' }, '*');
```

主程序用 iframe 加载关卡，所以你和主程序之间样式、脚本完全隔离——
`html`、`body` 选择器随便用，不会污染别人。

舞台固定 **1280 × 720**，主程序负责缩放到窗口，你按这个尺寸摆位置就行。

完整规则（目录结构、`cz:exit` 退出、不要动哪些文件、常见问题）见
**[`docs/level-api.md`](docs/level-api.md)**。

## 为什么文件夹名是人名，不是关卡号

这是整个架构里最重要的一条。

如果文件夹叫 `level07`，所有人都会默认它是「第 7 关」。等后期调整顺序，
要么改文件夹名（21 个路径全变，所有人的分支全部冲突），要么把「7 号同学」
硬塞到第 3 位，读代码的人永远要在脑内做一次翻译。

所以：

- **文件夹名 = 人的缩写**，只表示「这一格归谁」
- **剧情顺序 = `map.html` 里印章节点的排列顺序**，只表示「先玩哪一节」

两者之间没有耦合。调顺序就是挪几个 `<g class="seal">`，21 个人的文件夹一个字都不用改。
存档绑的是成员 `id` 而不是序号，所以怎么调顺序，进度都不会错乱。

成员不需要知道自己是第几关——只需要知道自己在做哪个事件。

## 协作

**分支**

| 分支 | 谁写 | 说明 |
| --- | --- | --- |
| `main` | 只有负责人 | 随时能展演的稳定版 |
| `develop` | 只能通过 PR 合入 | 日常集成分支，允许半成品 |
| `<你的缩写>` | 你自己 | 想怎么提交都行，坏了只影响自己 |

**三条边界**

1. **只写自己的格子。** `levels/<你的缩写>/` 之外的东西——`index.html`、
   `map.html`、`core/`、`assets/brand/`、`docs/`、别人的关卡——一律只读。
2. **草稿不进库，成品必须进库。** `_draft/` 随便扔（已被忽略）；
   别人 clone 下来必须有的素材放 `assets/`，必须提交。
3. **只推自己的分支。** 写完 push，提 PR 到 `develop`，不要直推 `main`。

**命名**：文件夹、文件名全小写 ASCII，多个词用连字符。关卡 `id` 定了就不改，
它是存档的键。
